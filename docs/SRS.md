## 2. 시스템 개요
### 2.1 프로젝트 목적

본 프로젝트는 Raspberry Pi 5와 Camera Module 3를 이용하여 실시간 영상을 수집하고, 영상 내 사람을 인식한 뒤, 사람의 자세와 행동 상태를 분석하여 낙상, 장시간 무반응, 비정상 상태 등의 위험 상황을 감지하고 알림 이벤트를 생성하는 시스템을 개발하는 것을 목적으로 한다.

분석 결과는 Raspberry Pi 3에서 운영되는 웹 서버, 데이터베이스, MQTT 브로커와 연동하여 저장, 표시, 알림 처리에 활용한다.

### 2.2 시스템 목표
| 구분 | 목표 |
| --- | --- |
| 영상 수집 | Camera Module 3를 통해 실시간 영상 획득 |
| 영상 전송 | Raspberry Pi 5에서 Raspberry Pi 3로 영상 또는 영상 접근 경로 제공 |
| 사람 인식 | 영상 내 사람 존재 여부, 사람 수, 위치 감지 |
| 상태 분류 | 서 있음, 앉음, 누움, 이동 중, 알 수 없음 등 상태 분류 |
| 위험 감지 | 낙상 의심, 장시간 무반응, 비정상 자세 지속 감지 | 
| 이벤트 전송 | MQTT를 통해 분석 결과와 위험 이벤트 전송 |
| 웹 연동 | Raspberry Pi 3 웹 서버에서 영상과 이벤트 표시 |
| 데이터 저장 | 위험 이벤트, 상태 변화, 장치 상태를 DB에 저장 |

## 3. 시스템 범위
### 3.1 포함 범위

이번 프로젝트의 1차 개발 범위는 다음과 같다.
```text
1. Raspberry Pi 5에서 Camera Module 3 영상 수집
2. Raspberry Pi 5에서 영상 스트리밍 또는 프레임 제공
3. 사람 감지
4. 자세 기반 상태 분류
5. 낙상 의심 및 장시간 무반응 감지
6. MQTT 기반 이벤트 전송
7. Raspberry Pi 3에서 이벤트 수신 및 저장
8. 기본 웹 화면에서 영상 및 이벤트 표시
9. 테스트 케이스 기반 검증
```

### 3.2 제외 범위

1차 개발 단계에서는 다음 기능을 제외한다.
```text
1. 의료 진단 기능
2. 뇌졸중, 질병 여부의 확정 판정
3. 얼굴 인식 기반 개인 식별
4. 다중 카메라 통합 관제
5. 클라우드 서버 연동
6. 모바일 앱 개발
7. 장기 행동 패턴 분석
8. 고도화된 게임/공부/수면 행동 분류
```
단, 위 항목은 2차 또는 3차 개발 단계에서 확장 가능하도록 설계 여지를 남긴다.

## 4. 전체 시스템 구성
4.1 시스템 구성도
```
[Camera Module 3]
        │
        │ CSI-2
        ▼
[Raspberry Pi 5 - Vision Node]
        │
        ├─ 영상 캡처
        ├─ 영상 스트리밍
        ├─ 사람 감지
        ├─ 자세 추정
        ├─ 상태 분류
        ├─ 위험상황 판단
        └─ MQTT Publish
                │
                │ LAN/Wi-Fi
                ▼
[Raspberry Pi 3 - Server Node]
        │
        ├─ MQTT Broker
        ├─ Web Server
        ├─ Database
        ├─ Event API
        └─ Dashboard
```

### 4.2 장치 역할
| 장치 | 역할 |
| Camera Module 3 | 영상 입력 장치 |
